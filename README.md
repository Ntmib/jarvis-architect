# jarvis-architect

Шаблон архитектуры личного Агента в Claude Code. Часть курса **«Архитектор нейросотрудников»** Дмитрия Ледовских.

## Что это такое

Готовый набор файлов, из которых собирается ваш персональный Агент. Архитектура — три уровня памяти:

**Главные файлы Агента (всегда читаются)**

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | Правила работы Агента в этой папке. Claude Code читает первым. |
| `SOUL.md` | Личность Агента: тон, ценности, что любит / не любит. |
| `MEMORY.md` | Долгосрочная память: профиль, проекты, инфраструктура, стек, предпочтения. |
| `GOALS.md` | Цели на квартал и активные направления. |

**Папки рабочей памяти (создаются и наполняются по ходу)**

| Папка | Что внутри |
|---|---|
| `memory/` | Дневники работы по дням (`YYYY-MM-DD.md`). Агент ведёт сам. |
| `knowledge/` | Справочники и инструкции (брендбук, чек-листы, гайды). Вы кладёте сюда вручную или просите Агента собрать. |

**Telegram-бот (опционально)**

| Папка | Что внутри |
|---|---|
| `bot/` | Telegram-бот на Grammy + Claude Code CLI. Текст, голосовые, фото, документы, видео. Поддержка медиагрупп (несколько фото за раз). Работает 24/7. |

## Урок 4. Установка архитектуры (локально)

Создайте **новую пустую папку** для Агента, откройте её в Claude Code и
скажите:

> **Установи мне архитектуру Агента из github.com/Ntmib/jarvis-architect**

Claude сам:
1. Скачает шаблон (`npx degit Ntmib/jarvis-architect .`)
2. Задаст 10 коротких вопросов: имя, чем занимаетесь, цели, стиль общения
3. Заполнит файлы вашими ответами
4. Покажет превью — вы подтвердите или попросите поправить
5. Если в папке уже настроен Git — предложит локальный коммит. Публикация в
   GitHub выполняется только отдельно, после проверки файлов и видимости
   репозитория

Время: 10–12 минут.

> Не устанавливайте шаблон поверх существующего проекта и не используйте
> `degit --force`: так можно перезаписать чужой `README.md`, `.gitignore` и
> другие файлы. Если папка не пустая, создайте рядом новую.

### Безопасность личной памяти

- В чистой папке `memory/` должен быть только `README.md`.
- Персональные файлы и дневники игнорируются Git по умолчанию и остаются на
  вашем компьютере.
- Не публикуйте `MEMORY.md`, `GOALS.md`, `USER.md`, `SOUL.md`, папки
  `memory/` и `knowledge/` в открытом репозитории.
- Не нажимайте Allow автоматически. Сначала прочитайте, какую команду и в
  какой папке хочет выполнить Claude Code.
- Для резервной копии используйте приватный репозиторий и перед push
  проверяйте список файлов.

## Урок 7. Перенос на сервер (VPS)

У вас уже есть заполненные файлы Агента на компьютере. Теперь переносим всё на сервер, чтобы Агент работал 24/7.

### Что нужно

- VPS на Beget (минимум 2 ГБ RAM)
- IP-адрес и root-пароль (получили при регистрации)
- VS Code с Claude Code на вашем компьютере

### Безопасный путь установки

Не отправляйте пароль root, токен Telegram-бота или коды авторизации в чат с
ИИ. Первичная установка выполняется во встроенной консоли хостинга, где пароль
вводится скрыто.

1. Откройте панель Beget → VPS → Консоль.
2. Войдите как `root`.
3. Выполните:

```bash
wget -O /root/setup-agent.sh https://raw.githubusercontent.com/Ntmib/jarvis-architect/main/setup-server.sh
bash /root/setup-agent.sh
rm /root/setup-agent.sh
```

4. Настройте VS Code Tunnel по подсказкам скрипта.
5. Перенесите файлы Агента через проводник VS Code в
   `/home/agent/workspace/`.

Полная безопасная инструкция для Claude Code находится в
`server/INSTALL-SERVER.md`.

### Telegram-бот

Токен вводится только в консоли VPS со скрытым вводом:

```bash
wget -O /root/setup-agent-bot.sh https://raw.githubusercontent.com/Ntmib/jarvis-architect/main/setup-bot.sh
bash /root/setup-agent-bot.sh
rm /root/setup-agent-bot.sh
```

Не вставляйте токен в промпт, файл проекта или командную строку. Скрипт сам
запросит его безопасно и запишет в закрытый `.env`.

### Настройте VS Code Tunnel

Claude даст инструкцию. Если коротко:
1. Зайдите в панель Beget → ваш VPS → **Консоль**
2. Получите безопасное имя туннеля и запустите авторизацию от пользователя
   `agent`:

```bash
TUNNEL_NAME=$(systemctl cat agent-tunnel.service | sed -n 's/.*--name //p' | tail -1)
sudo -u agent -H code tunnel --accept-server-license-terms --name "$TUNNEL_NAME"
```

3. Откройте появившуюся ссылку и введите код на GitHub.
4. Вернитесь в консоль и нажмите `Ctrl+C`.
5. Запустите подготовленный сервис, который работает без root-прав:

```bash
systemctl enable --now agent-tunnel.service
```

### Подключитесь из VS Code

1. Откройте VS Code на компьютере
2. Слева найдите **Remote Explorer** (иконка монитора)
3. В разделе **Tunnels** появится ваш сервер — нажмите на него
4. Готово — вы работаете на сервере как в обычной папке

## Если установка через консоль не завершилась

Не отправляйте пароль root в Claude Code. Откройте встроенную консоль VPS и
повторно запустите безопасный установочный скрипт:

```bash
wget -O /root/setup-agent.sh https://raw.githubusercontent.com/Ntmib/jarvis-architect/main/setup-server.sh
bash /root/setup-agent.sh
rm /root/setup-agent.sh
```

После завершения подключитесь через VS Code Tunnel и перенесите файлы через
проводник VS Code. Подробности — в `server/INSTALL-SERVER.md`.

├── INSTALL.md             ← wizard для Claude Code (урок 4, удаляется после)

├── bot/                   ← Telegram-бот

│   ├── package.json       ← зависимости
│   └── agent-bot.service  ← systemd-сервис
├── server/
│   └── INSTALL-SERVER.md  ← инструкция для Claude: установка на VPS
├── examples/              ← пример заполненного Агента
├── docs/
│   └── s                  ← копия setup-server.sh для GitHub Pages
└── .claude/
    ├── CLAUDE.md           ← проектные инструкции для Claude Code
    ├── settings.json       ← настройки разрешений (светофор) + плагин Superpowers

        ├── README.md       ← гайд по скиллам (урок 5)
        ├── server-setup/
        │   └── SKILL.md    ← скилл установки на VPS
        ├── discovery-interview/
        │   └── SKILL.md    ← сбор ТЗ через интервью

        │   └── SKILL.md    ← написание контента
