# Безопасная установка Агента на VPS

## Когда использовать

Пользователь просит установить, перенести или развернуть Агента на VPS.

## Главное правило

Не проси присылать в чат пароль root, токен Telegram-бота, приватный ключ или
код авторизации. Не используй автоматический ввод пароля и не отключай
проверку подлинности SSH-сервера.

## Что делать

1. Прочитай `server/INSTALL-SERVER.md` в корне шаблона.
2. Следуй только этой инструкции: первичная установка выполняется самим
   пользователем во встроенной консоли хостинга.
3. Для передачи файлов используй VS Code Tunnel и проводник VS Code, а не SCP
   с паролем.
4. Для Telegram-бота направь пользователя к `setup-bot.sh`: токен вводится в
   консоли VPS скрыто и не попадает в переписку.
5. Не публикуй личные файлы в GitHub и не выполняй push без отдельного
   подтверждения и проверки приватности репозитория.

Если безопасная инструкция недоступна, остановись и попроси пользователя
открыть файл `server/INSTALL-SERVER.md`. Не восстанавливай старый сценарий по
памяти.
