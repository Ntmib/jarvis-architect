# Безопасность шаблона

## Личная память

Файлы `MEMORY.md`, `GOALS.md`, `USER.md`, `SOUL.md`, дневники `memory/` и
документы `knowledge/` могут содержать личные данные, проекты, аккаунты,
инфраструктуру и рабочие решения. После установки они игнорируются Git по
умолчанию и должны оставаться локальными.

Если нужна синхронизация между компьютерами:

1. создайте приватный репозиторий;
2. проверьте каждый файл перед добавлением;
3. не коммитьте `.env`, токены, пароли, cookies и приватные ключи;
4. перед push проверьте `git status` и `git diff --cached`.

## Разрешения Claude Code

Шаблон использует стандартный режим разрешений. Не включайте
`bypassPermissions` на обычном компьютере. Разрешайте действие только когда
понимаете команду, путь и возможный результат.

## Чистота шаблона

В папке `memory/` публичного шаблона должен находиться только `README.md`.
Рабочие дневники владельца шаблона, учеников или разработчиков публиковать
нельзя.

## Если секрет уже попал в GitHub

Удаления файла в новом коммите недостаточно: значение остаётся в истории.
Сначала отзовите и замените секрет, затем очистите историю репозитория.
